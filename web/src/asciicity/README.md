# Vendored from AsciiCity

`render/` is a verbatim copy of `src/render/{style.ts,post.ts,scene.ts,crt.ts,crt.css,styles/*}`
from https://github.com/ubyjvovk/asciicity (same author), copied 2026-09-04.
It is the render-style plug-in system: a three.js scene rendered to a
low-resolution target and turned into glyphs by a fragment-shader style
(`ascii`, `amber`, `gloom`, `solarized`, `matrix`, …). Do not edit these
files here — improve them in AsciiCity and re-copy. The `matrix` style's
katakana bitmaps derive from GNU Unifont (SIL OFL 1.1 / GPL v2+ with the
font-embedding exception).
