## Goal
Three pure modules every terminal mode needs: the ASCII quantizer that
turns a `FrameBuffer` into a `ScreenGrid` using AsciiCity's ramp/gamma
formulas (`docs/architecture.md` §5.4), the `Screen` writer that paints a
`ScreenGrid` with minimal ANSI output (§6.1), and the key parser (§6.2).

## Context
- Read `docs/architecture.md` §5.1, §5.4, §6.1, §6.2. Types are PM-owned in
  `src/model/types.ts` (`FrameBuffer`, `ScreenGrid`, `ScreenCell`).
- `src/render/ascii.ts`: `DEFAULT_RAMP` (the 68-glyph string in §5.4 —
  copy it exactly; it starts with a space and ends with `$`),
  `glyphIndex(lum, count, gamma)`, `quantize(fb, opts?: QuantizeOptions):
  ScreenGrid` and `quantizeInto(fb, grid, opts?)` (reuses the grid's cell
  objects — no per-frame allocation). Defaults: exposure 1.7, gamma 0.45.
  Overlay cells print `overlayCh` in `overlayRgb` (exposed, clamped) on
  black. Never let a non-overlay cell produce a character outside the ramp.
- `src/term/screen.ts`: `diff(prev: ScreenGrid | null, next: ScreenGrid):
  string` — emits `CSI row;col H` moves only when the cursor is not already
  there, `CSI 38;2;r;g;b m` / `CSI 48;2;r;g;b m` only when the colour
  changes, skips runs of identical cells, and ends with `CSI 0 m`. `null`
  prev (or a size change) = full repaint after `CSI 2 J`. `class Screen`
  wraps it over a `TermIO {write(s), columns, rows, onResize(cb), onKey(cb)}`
  with `paint(grid)`, `invalidate()`, `enter()` (alt screen `CSI ?1049 h`,
  hide cursor `CSI ?25 l`) and `leave()` (reverse, reset SGR). Optional
  `CellStyle` bits (bold/inverse) via SGR 1 / 7 on `ScreenCell.attrs` are
  **not** in the PM type — if you need them, add an optional
  `attrs?: number` field only through a `## Questions` block; otherwise
  express inverse video by swapping fg/bg.
- `src/term/input.ts`: `parseKeys(buf: Uint8Array, pending: Uint8Array):
  {events: KeyEvent[], rest: Uint8Array}` — a pure incremental parser;
  `KeyEvent {key: string; ctrl: boolean; shift: boolean; alt: boolean;
  seq: string}`. `key` is the character for printable input, else one of
  `Escape Enter Tab Backspace Up Down Left Right Home End PageUp PageDown
  Insert Delete F1 F2 F3 F4 F5 … F12`. Recognise CSI (`ESC [ … final`),
  SS3 (`ESC O x`), modifiers `;2` (shift) `;3` (alt) `;5` (ctrl), `ESC x`
  as alt+x, bytes 1–26 as `Ctrl+letter` (`key` = the lower-case letter,
  `ctrl: true`; byte 13 is `Enter`, 9 `Tab`, 127/8 `Backspace`). A lone
  ESC stays in `rest` (the caller applies the 25 ms timeout and calls
  `flushEscape()` which returns the `Escape` event). UTF-8 multi-byte
  printables decode to one event.
