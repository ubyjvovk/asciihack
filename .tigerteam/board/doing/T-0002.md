## Goal
Write `bridge/nh-bridge.c`: links `build/nethack/lib/libnethack.a`,
registers the shim callback, prints a `hello` line, runs `nhmain`, and
forwards every window-procedure call as one JSON line on stdout, reading
replies on stdin — exactly the protocol in `docs/architecture.md` §3. This
is the only C code in the project and the foundation for everything else.

## Context
- **Read first**: `docs/architecture.md` §3 (all of it: framing, per-call
  table, glyph info, hello) and `src/engine/protocol.ts` (the TypeScript
  side of the same shapes — names and JSON keys must match it exactly).
- The shim: `nethack/win/shim/winshim.c`. The non-emscripten branch defines
  the callback type
  `void cb(const char *name, void *ret_ptr, const char *fmt, ...)` and the
  `DECLCB`/`VDECLCB` lines (~117–235) list every call with its `fmt`
  string and argument order. Format letters: first char = return type;
  then `i` int, `s` `char *`, `p` pointer, `c` char, `b` boolean,
  `0`/`1`/`2` small ints — through varargs everything narrower than `int`
  arrives as `int`, pointers as `void *`. Note the shim's own comments:
  `select_menu`'s `menu_list` is an **output** parameter; `status_update`'s
  second argument is a `long *` for `BL_CONDITION`, a `char *` otherwise,
  and `NULL` for `BL_FLUSH`/`BL_RESET`.
- Semantics of each window proc: `nethack/doc/window.txt`; reference
  implementation `nethack/win/tty/wintty.c`. Player name global: grep
  `plname[PL_NSIZ]` in `nethack/include/decl.h` and find the struct
  instance it lives in. `getlin` buffer size: `BUFSZ`. Extended commands:
  `extcmdlist[]` in `nethack/src/cmd.c` / `include/func_tab.h`. Glyph
  macros: `nethack/include/display.h` (`glyph_is_*`, `glyph_to_*`);
  symbol X-macros: `nethack/include/defsym.h`; `defsyms[]` in
  `nethack/src/drawing.c`; `dlb_fopen`/`dlb_fgets` in `nethack/include/dlb.h`.
- Build: add a `bridge` variant to `scripts/nethack-build.sh` (T-0001 wrote
  it; it must already produce `build/nethack/lib/{libnethack.a,liblua.a,
  include/,cflags.txt,playground/}`). Compile with
  `gcc -std=gnu99 -Wall -Wextra -Werror $(cat build/nethack/lib/cflags.txt)
  -I build/nethack/lib/include bridge/nh-bridge.c -o build/nethack/bridge/nh-bridge
  build/nethack/lib/libnethack.a build/nethack/lib/liblua.a -lm` plus
  whatever else the link needs (`-lncurses`/`-ltinfo` for termcap symbols
  if unresolved). Keep the recipe in `bridge/Makefile` and have the script
  call it. Copy `build/nethack/lib/playground/` to
  `build/nethack/bridge/playground/` (the bridge's default `NETHACKDIR`).
- JSON output: hand-written writer with a `json_str()` escaper per §3.2
  (bytes below 0x20 and at or above 0x80 become `\u00XX`). JSON input: a
  small hand-written parser for the reply subset in §3.2 only; put it in
  `bridge/reply.c`/`reply.h` with a tiny test program `bridge/reply_test.c`
  run by the Makefile's `test` target (cases: int ret, negative int,
  string ret with escapes `\"`, `\\`, `\n`, ``; `null`; `true`;
  `selected` with two entries; `x`/`y`/`mod`; unknown keys skipped;
  garbage line → parse failure).
- Menus: keep a per-window growable array of `anything` identifiers,
  reset by `start_menu`; `identIndex` −1 when the identifier is all-zero
  (`memcmp` against a zeroed `anything`). `select_menu` mallocs the
  `MENU_ITEM_P` array (NetHack frees it).
- Flushing: `setvbuf(stdout, NULL, _IOFBF, 1 << 18)`; `fflush` before every
  blocking read, in `delay_output` (+ `usleep(50000)`), `mark_synch`,
  `wait_synch`, and at exit.
- Startup: `main` prints `hello`, calls `shim_graphics_set_callback`, then
  `return nhmain(argc, argv)` (wrap so the `exit` line is printed on
  return; also install an `atexit` hook that prints it if NetHack calls
  `exit()` itself, once only). `NETHACKDIR` comes from the environment;
  argv passes through untouched.
- Smoke: `scripts/bridge-smoke.ts` (run with `npx tsx`) copies
  `build/nethack/bridge/playground/` to a temp dir, spawns the bridge with
  `NETHACKDIR=<tmp>`, `NETHACKOPTIONS=role:Valkyrie,race:human,gender:female,align:neutral,name:smoke,pettype:none`
  and `-u smoke`, then answers: `create_nhwindow` → ids 1, 2, 3, …;
  `askname` → `"smoke"`; `player_selection_or_tty` → `false` (document what
  you observe); `yn_function` → `def`; `select_menu` → cancel (−1) unless
  the prompt forces a choice; `display_nhwindow` blocking → 0;
  `nhgetch`/`nh_poskey` → first time: assert at least 200 `print_glyph`
  calls were seen and one of them carried `MG_HERO`, print
  `hero at (x,y), N map cells`, reply with ESC, then kill the bridge and
  exit 0. Any `exit` line before that → exit 1 with the reason.
  `tests/bridge.test.ts` wraps the same flow under
  `describe.skipIf(!existsSync('build/nethack/bridge/nh-bridge'))`.
- Add `nethack-lib` (`bash scripts/nethack-build.sh lib`) and `bridge`
  (`bash scripts/nethack-build.sh bridge && npx tsx scripts/bridge-smoke.ts`)
  stages to `scripts/check.sh` after `build`.

## Acceptance criteria
- [ ] `bash scripts/nethack-build.sh bridge` builds `build/nethack/bridge/nh-bridge`
      with `-Wall -Wextra -Werror` and runs `make -C bridge test` (reply
      parser cases above) successfully.
- [ ] `npx tsx scripts/bridge-smoke.ts` exits 0 and prints the hero line;
      `bash .tigerteam/scripts/run-tests.sh tests/bridge.test.ts` exits 0
      with the bridge built.
- [ ] The first stdout line is a `hello` whose `S` has `S_vwall`, `S_room`,
      `S_ndoor`; `cmap` has one entry per `S_*` index; `nhw`, `bl`, `pick`,
      `atr`, `mg`, `clr`, `blmask` and `extra.extcmds` are present
      (`extcmds` has an entry named `quit`).
- [ ] Every `print_glyph` argument matches §3.4 (`glyph, ch, color, cls,
      idx, flags`); the hero's glyph has `MG_HERO` set in `flags`; wall
      cells have `cls: "cmap"` with `idx` equal to a wall `S_*` index.
- [ ] Every line the bridge prints parses with `JSON.parse` (the smoke
      script asserts this for all lines it reads).
- [ ] Killing stdin (EOF) while the bridge waits for a reply makes it print
      an `exit` line with a `reason` and exit 2 within 1 s.
- [ ] `bash scripts/check.sh` passes end to end with the new stages.
- [ ] `bash .tigerteam/scripts/run-tests.sh` exits 0.
- [ ] `docs/bridge.md`: how to build and run the bridge by hand (with a
      one-line `printf ... | nh-bridge` example), what `player_selection_or_tty`
      turned out to mean, any place where the shim's actual behaviour differs
      from `docs/architecture.md` §3 (list them explicitly — the PM will
      update the contract), and the reply parser's limits.
- [ ] No files changed outside scope
