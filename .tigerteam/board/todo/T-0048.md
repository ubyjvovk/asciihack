## Goal
With the GPU path live, every frame on the WebGL2 backend logs

```
THREE.TSL: TypeError: Cannot read properties of null (reading 'sampleEnvironmentBRDF')
  at sampleEnvReflection (SSRNode.js:1051)
```

T-0041 put SSR on the **stochastic** path for that backend (three r185's
mirror path cannot link there), and the stochastic path resolves rays that
*miss* the screen against an environment map — which is `null`, because
`ssr()`'s `environmentNode` option was never supplied. Reflections that leave
the screen therefore contribute nothing and the console fills up. Give the
scene a small environment and pass it.

## Context
- **The sources are vendored in-repo at `vendor/afterburn/` (read-only).**
  `~/afterburn` is not visible inside the worker container. Afterburn built a
  **PMREM sky environment** in `vendor/afterburn/src/render/moods.js`; T-0038
  deliberately dropped it along with the sky dome, which is where this hole
  came from.
- `node_modules/three/examples/jsm/tsl/display/SSRNode.js` documents the
  option: *"`environmentNode` — Equirectangular HDR environment map with
  CPU-side `image.data`. **Not compatible with PMREM / `scene.environment`
  cubemaps**"*. So this must be a plain `THREE.DataTexture`, not a PMREM
  render target and not `scene.environment`.
- **The design, decided.** In `moods.ts`, add
  `export function moodEnvironment(mood: Mood): THREE.DataTexture` building a
  **32 × 16 equirectangular `DataTexture`** (`RGBAFormat`, `HalfFloatType`,
  `mapping = THREE.EquirectangularReflectionMapping`): a vertical gradient
  from `mood.fill.sky` at the top pole to `mood.fill.ground` at the bottom,
  both multiplied by `mood.fill.intensity`, with no horizontal variation.
  It is 512 texels — build it once per mood and cache it on the `Atmosphere`,
  disposing the previous one when the mood changes.
- `Atmosphere` exposes the current texture (`get environment()`), and
  `createPipeline` gains an `environment?: THREE.Texture | null` option
  forwarded to `ssr(..., { environmentNode })`. Pass it on **both** backends —
  it is harmless on the mirror path and gives misses something plausible.
- A dungeon's environment is *dim on purpose*: this is not meant to light the
  scene, it is what a ray sees when it leaves the screen. If it visibly
  brightens the room, the gradient is too strong — say so in the report.
