## Goal
The user's screenshot (142×75, cyber theme, hero in a corridor facing the
unknown): the never-seen space renders as a solid blue field of `?`, the
wall bodies as dense `(`/`)` fields, and the floor comes out yellow. The
renderer's levels are right (T-0023); the quantizer's tone curve is not:
`dens = v^0.45` with no black point turns 3 % brightness into a mid-density
glyph, and normalising the hue at full brightness turns any faint colour
cast in a dark cell into a saturated one. Give the quantizer a black
point, a steeper gamma and darkness-dependent desaturation, for every
theme, so dark surfaces quantize to sparse dots or nothing and stay grey.

## Context
- `docs/terminal.md` (quantizer + themes), `src/render/ascii.ts`
  (`glyphIndex`, `cellFromRgb`, `quantize`, `quantizeInto`,
  `QuantizeOptions`), `src/render/themes.ts` (`themeMix`, `amberMix`,
  `amberDensity`). Renderers and their goldens use test-local ramps and
  are not affected; UI tests that replay fixtures through the quantizer
  must stay green (adjust expectations only where a row legitimately
  becomes sparser).
- New `QuantizeOptions.blackPoint` (default `0.08`) and new defaults
  `gamma 0.7` (was 0.45), `exposure 1.7` unchanged. Density for cyber /
  gloom / solarized: `v = max(c)` after exposure, `vc = clamp((v −
  blackPoint) / (1 − blackPoint), 0, 1)`, `dens = vc^gamma`,
  `idx = round(dens · (ramp.length − 1))` — `vc = 0` is the space glyph.
  Amber keeps its own `amberDensity` (it already has a black point) but
  uses the same `blackPoint` option value in place of its hard-coded 0.06.
- Desaturation (all four themes, before the theme mix): `raw = c /
  max(v, 0.02)`; `grey = 0.299·raw.r + 0.587·raw.g + 0.114·raw.b`;
  `sat = clamp(dens · 1.5, 0, 1)`; `tint = grey + (raw − grey)·sat`, then
  the existing brightness fold `tint · clamp(dens·0.7 + 0.4)`. Dark cells
  come out grey, bright cells keep their hue. Overlay glyphs (sprites) are
  untouched — their colour is meaningful.
- Worked numbers (T-0023's levels, cyber): veil 0.03·1.7 = 0.05 → below
  the black point → space; wall body 0.14 → v 0.24 → vc 0.17 → dens 0.29
  → a sparse glyph (`,`/`:`); floor 0.10 → v 0.17 → vc 0.10 → dens 0.20
  → `.`/`'`; floor grid line 0.30 → v 0.51 → dens 0.6 → clearly visible;
  wall-top edge 0.75 → v 1.27 → `$`. That is the wanted grammar.
- Update `docs/terminal.md` formulas and the theme section; note the
  default change.
