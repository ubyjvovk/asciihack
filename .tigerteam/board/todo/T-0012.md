## Goal
NetHack's `pline()` (`nethack/src/pline.c` ~line 239) sends every message
through `raw_print()` while `iflags.window_inited` is false; every real
window port sets that flag to TRUE at the end of its `init_nhwindows`
(`win/tty/wintty.c` ~1885, `win/curses/cursmain.c` ~493), but the shim
port never does, so today all game messages bypass the message window
(no message-window `putstr`, no history, no forced `--More--`). Set the
flag in the bridge right after forwarding `init_nhwindows`.

## Context
- `bridge/nh-bridge.c`, the `shim_init_nhwindows` branch of
  `handle_callback`: after `emit_call_end_noreply()`, add
  `iflags.window_inited = TRUE;` (`iflags` is the global from `hack.h`,
  already available — the bridge already uses `svp.plname`).
- Verify with `bash scripts/nethack-build.sh bridge` and
  `npx tsx scripts/bridge-smoke.ts`. After the change the welcome message
  ("… welcome to NetHack!  You are a …") must arrive as a `putstr` call
  on the message window (the window id the client returned for
  `create_nhwindow(NHW_MESSAGE)`), not as `raw_print`.
