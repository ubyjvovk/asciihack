## Goal
Menus, text windows and prompts are unreadable over the 3D viewport: the
scene shows through the box. `paintBox` (src/ui/grid.ts) draws only the
border and the title; interior cells keep whatever the scene painted, and
short lines leave the rest of the row showing the scene. Give every
overlay box an opaque panel.

## Context
- `src/ui/grid.ts` `paintBox` / `putText` / `UI_BG`; every overlay in
  `src/ui/overlays.ts` calls `paintBox` then `putText` per line.
- Fix in `paintBox`: before drawing the border, fill **every** cell of the
  `w × h` box with `' '`, fg `UI_FG`, bg `PANEL_BG` (new export in
  `grid.ts`: `[18, 18, 26]` — a hair lighter than the black scene so the
  panel is visible against a dark background too); draw the border and
  title on the same bg; make the returned `inner` rect's default text bg
  `PANEL_BG` (give `putText` callers in overlays that bg — simplest: add
  an optional `bg` to the overlays' text calls, or a `putPanelText`
  helper in grid.ts that uses `PANEL_BG`). Also pad: clear one extra
  column on each side and one extra row above/below the box (a margin, in
  `UI_BG` black) so text never touches the scene glyphs.
- Do not touch the message line / `--More--` painter (it already uses a
  solid `UI_BG`).
