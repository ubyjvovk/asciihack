## Goal
The first playable milestone: `npm start -- --mode=classic` runs NetHack in
the terminal through the bridge and session model, drawing the 80×21 map
with colours, the message line with `--More--`, the two status lines, and
boxed overlays for menus, text windows, `yn` and `getlin` prompts. The
shell (layout, message/status handling, request handling, mode switching)
is written so the fps and ortho modes only add a viewport painter.

## Context
- Read `docs/architecture.md` §4.4, §6 (all), §7. Building blocks already
  landed: `NethackSession` (`src/engine/session.ts`, see `docs/engine.md`),
  `Screen`/`diff`/`TermIO` and `parseKeys` (`src/term/screen.ts`,
  `src/term/input.ts`, see `docs/terminal.md`), `ScreenGrid`/`ScreenCell`
  and `clrToRgb` (`src/model/types.ts`).
- `src/ui/app.ts`: `App` takes `{session, term: TermIO, mode}` and owns the
  loop: on session `change` → compose a `ScreenGrid` (§6.3 layout) →
  `screen.paint()`. Composition = `paintMessageLine` + the mode's
  `paintViewport(grid, rect)` + `paintStatus` + `paintOverlay` for the
  pending request. Keys: while an overlay is open the overlay consumes
  them; otherwise the mode's `handleKey` decides (classic: forward
  everything to NetHack via `session.answer` when a key request is
  pending, else queue one key). `F1/F2/F3` switch modes (fps/ortho modes
  do not exist yet: switching to them shows a "not yet" banner and stays
  in classic — keep the hook). `Ctrl+L` → `screen.invalidate()`.
- `src/ui/modes/classic.ts`: paints the 80×21 map from `session.map`
  (`top` glyph char + `clrToRgb(color)`, hero cell inverse-video) into the
  viewport; wider terminals centre it.
- `src/ui/overlays.ts`: menu overlay (paging with `>`/`<`, accelerators,
  PICK_NONE/ONE/ANY behaviour like tty: Enter confirms, ESC cancels, item
  toggles for PICK_ANY, count prefixes optional), text overlay (paging,
  any key/ESC dismisses), `yn` prompt (on the message line, shows choices
  and default, ESC → the `q`/`n`/default rule from `wintty.c`), `getlin`
  (line editor with Backspace, ESC cancels → `""`), ext-cmd prompt
  (`#` line with prefix completion over `hello.extra.extcmds`, Enter →
  index, ESC → −1), `--More--` (any key continues).
- `src/ui/status.ts`: `session.statusLines()` → two rows, bottom of the
  screen, truncated to the width.
- `src/term/tty.ts`: real `TermIO` over `process.stdin/stdout`: raw mode,
  alt screen, hide cursor, SIGWINCH → `onResize`, restore everything on
  exit (also on uncaught errors and SIGTERM). Must be the only file that
  touches `process.stdin/stdout` directly.
- `src/cli.ts`: flags `--mode=classic|fps|ortho` (default `fps`, which
  falls back to classic with the banner until T-0007 lands), `--name=`,
  `--bridge=` (default `build/nethack/bridge/nh-bridge`), `--playground=`
  (default `build/nethack/bridge/playground`, copied to
  `~/.asciihack/playground` on first run so saves persist and the build
  dir stays clean), `--options=` (extra `NETHACKOPTIONS`). Prints a
  helpful error if the bridge binary is missing.
- Tests use a fake `TermIO` (captures written bytes and grid; injects keys
  and size) and a `NethackSession` fed from the T-0003 fixtures
  (`tests/fixtures/bridge/*.jsonl`) — no real bridge.
