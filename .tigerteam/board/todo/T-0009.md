## Goal
`Screen.remember()` (src/term/screen.ts) reuses its private copy of the last
painted cells, but never reallocates it when a grid with more cells is
painted while `prev` is non-null, so `dst` is `undefined` and the paint
throws `TypeError: Cannot set properties of undefined`. Make the private
copy grow/shrink with the painted grid.

## Context
- `docs/architecture.md` §6.1; `docs/terminal.md` "Screen" section (update
  its sentence about the private copy).
- Reproduction (PM probe): paint a 4×2 grid, then paint a 6×3 grid on the
  same `Screen` **without** calling `invalidate()` → throws. `diff()` already
  handles the size change (full repaint); only `remember()` is wrong.
- Fix inside `remember()`: when `grid.width * grid.height` differs from the
  stored copy's cell count, rebuild the copy's `cells` array to the new size
  (allocation only on size change; the steady state stays allocation-free).
