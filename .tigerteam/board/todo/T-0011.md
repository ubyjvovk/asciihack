## Goal
Give the terminal the same alternate looks AsciiCity has: `gloom` (dark
glyphs over a bright grey ground), `solarized` (ink on cream paper) and
`amber` (warm monochrome phosphor), selectable through `QuantizeOptions`.
The formulas below are AsciiCity's shader mixes, already expressed as pure
TypeScript; port them term for term so the two projects look alike.

## Context
- `docs/architecture.md` §5.4 and `docs/terminal.md` (quantizer section).
  `src/render/ascii.ts` (T-0006) computes, per non-overlay cell:
  `c = rgb·exposure`, `v = max(c)`, `dens = clamp(v)^gamma`, `ch =
  ramp[idx(dens)]`, `tint = c / max(v, 0.02) · clamp(dens·0.7 + 0.4)`.
  Today the output is `fg = tint`, `bg = black` — that is theme `cyber`.
- Add `theme?: 'cyber' | 'gloom' | 'solarized' | 'amber'` (default
  `cyber`) to `QuantizeOptions`. Put the mixers in `src/render/themes.ts`
  as pure functions and call them from `ascii.ts`; the glyph choice
  (`ch`) is unchanged for cyber/gloom/solarized; amber uses its own
  density (below) for the glyph index too.
- In a shader the glyph coverage `mask` is a per-pixel value; in a
  terminal the glyph is drawn by the terminal, so use **`mask = 1` for
  the foreground colour and `mask = 0` for the background colour** of the
  same cell. That is: `fg = mix(theme, tint, v, 1)`, `bg = mix(theme,
  tint, v, 0)`.
- Overlay glyphs (monsters/objects) keep their own colour as fg; their bg
  is the theme's `mask = 0` colour for a black input (so they sit on the
  paper/ground, not on black).
- The AsciiCity mixers (copy verbatim, then adapt names). `tint` is the
  hue at full brightness **before** the `dens·0.7 + 0.4` fold for amber
  (`rawTint`), after it for the others; `v` is the exposed max channel:

```ts
export function themeMix(tint: [n,n,n], v: number, mask: number, theme: number): [n,n,n] {
  const normalCol = [tint[0]*mask, tint[1]*mask, tint[2]*mask];
  const lumT = 0.299*tint[0] + 0.587*tint[1] + 0.114*tint[2];
  // smoothstep(0.92, 1.0, clamp(v)) — hot keeps sun/moon/lit windows bright
  const sx = clamp01((clamp01(v) - 0.92) / 0.08); const hot = sx*sx*(3 - 2*sx);
  // gloom (theme 1)
  const gWash = [(lumT + (tint[0]-lumT)*0.75)*0.2, (lumT + (tint[1]-lumT)*0.75)*0.2, (lumT + (tint[2]-lumT)*0.75)*0.2];
  const gGlyph = [gWash[0] + (tint[0]*0.9 - gWash[0])*hot, gWash[1] + (tint[1]*0.9 - gWash[1])*hot, gWash[2] + (tint[2]*0.9 - gWash[2])*hot];
  const gloomBg = [0.72, 0.73, 0.75];
  const gloomCol = [gloomBg[0] + (gGlyph[0]-gloomBg[0])*mask, gloomBg[1] + (gGlyph[1]-gloomBg[1])*mask, gloomBg[2] + (gGlyph[2]-gloomBg[2])*mask];
  // solarized (theme 2): base00 ink on base3 paper, hot → solarized yellow
  const sInk = [(0.396 + (tint[0]-0.396)*0.5)*0.75, (0.482 + (tint[1]-0.482)*0.5)*0.75, (0.514 + (tint[2]-0.514)*0.5)*0.75];
  const solY = [0.71, 0.54, 0.0];
  const sGlyph = [sInk[0] + (solY[0]-sInk[0])*hot, sInk[1] + (solY[1]-sInk[1])*hot, sInk[2] + (solY[2]-sInk[2])*hot];
  const paper = [0.992, 0.965, 0.89];
  const solCol = [paper[0] + (sGlyph[0]-paper[0])*mask, paper[1] + (sGlyph[1]-paper[1])*mask, paper[2] + (sGlyph[2]-paper[2])*mask];
  if (theme < 0.5) return normalCol; if (theme < 1.5) return gloomCol; return solCol;
}
/** amber density: black-point cut then steeper gamma: pow(clamp((v-0.06)/0.94), gamma*1.5) */
export function amberDensity(v: number, gamma: number): number { return Math.pow(clamp01((v - 0.06) / 0.94), gamma * 1.5); }
export function amberMix(rawTint: [n,n,n], v: number, mask: number, gamma: number): [n,n,n] {
  const aDens = amberDensity(v, gamma);
  const gr = clamp01((rawTint[1] - 0.5*(rawTint[0] + rawTint[2])) * 2);
  const chroma = [1.0 + (0.75-1.0)*gr, 0.62 + (0.85-0.62)*gr, 0.18 + (0.32-0.18)*gr];
  const t = clamp01((v - 0.82) / 0.18); const aHot = t*t*(3 - 2*t);   // smoothstep(0.82, 1.0, v)
  const scale = 0.18 + 0.82*aDens;
  const glyphC = [chroma[0]*scale + (1.0 - chroma[0]*scale)*aHot, chroma[1]*scale + (0.88 - chroma[1]*scale)*aHot, chroma[2]*scale + (0.58 - chroma[2]*scale)*aHot];
  return [glyphC[0]*mask, glyphC[1]*mask, glyphC[2]*mask];
}
```

  For `amber` the glyph index uses `amberDensity(v, gamma)` instead of
  `dens`. Colours are then clamped and scaled to 0–255 like today.
