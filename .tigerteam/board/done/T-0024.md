## Goal
Let the player tune the first-person field of view while playing, keep
the choice across runs, and make the compass ribbon span the real field
of view instead of a hard-coded 70°.

## Context
- `docs/ui.md`, `src/ui/modes/fps.ts` (owns the render call; T-0023 added
  `RaycastOptions.vFovDeg` and `horizonFrac`, and the derived horizontal
  FOV formula `hFov = 2·atan(tan(vFov/2) · cols / (rows · cellAspect))`),
  `src/ui/compass.ts` (ribbon: today 20 columns per 45° and a fixed
  ±35° window), `src/ui/app.ts` (global keys, message-line toast if one
  exists — `--More--`/message painter), `src/cli.ts` (flags).
- **Keys.** `F6` narrows, `F7` widens the vertical FOV by 5° per press,
  clamped to 40°–100°; each press shows a one-line toast on the message
  line for ~1.5 s (`FOV 65°`) without touching NetHack's messages, and
  triggers a repaint. Works in fps only (ortho/classic ignore them).
- **Default theme becomes `amber`** (user preference after comparing with
  AsciiCity's amber render): `--theme` default and the settings default
  are `amber`; `F5` still cycles cyber → gloom → solarized → amber.
  Update the README flag table and `docs/ui.md`.
- **Flag.** `--fov=<deg>` sets the vertical FOV at start (same clamp).
  Precedence: flag > saved setting > default 60.
- **Settings file** (`src/ui/settings.ts`): `~/.asciihack/settings.json`
  (path from `ASCIIHACK_HOME` like the playground), shape
  `{ "fov": 60, "theme": "amber", "minimap": true }`; loaded at start
  (missing/invalid file → defaults, never crash), written atomically
  (`.tmp` + rename) whenever FOV, theme (`F5`) or minimap (`F4`) changes.
  The CLI flags override the file for that run and are then saved too.
  Pure `parseSettings(text)` / `serializeSettings(s)` with the I/O in two
  thin functions.
- **Compass.** `paintCompass(grid, rect, yawRad, hFovRad)`: the ribbon's
  visible window is `±hFov/2` and its scale is `(rect.width·0.34) / hFov`
  columns per radian (the ribbon stays ~a third of the width), so the
  headings you see are the headings in view. The fps mode computes `hFov`
  with the same formula as the renderer (export a helper from
  `raycast.ts` if one does not exist — read-only use, do not edit
  `raycast.ts`; if it lacks one, block with `## Questions`).
- README: key table (`F6`/`F7`), the `--fov=` flag, the settings file.
