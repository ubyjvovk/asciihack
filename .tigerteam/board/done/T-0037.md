## Goal
Port the sibling project's renderer bootstrap and post-processing stack —
`~/afterburn/src/render/{renderer.js,pipeline.js}` → `web/src/gpu/{renderer,
pipeline}.ts` — as strict TypeScript. This ticket delivers the node graph and
its quality ladder only; no dungeon scene and no page integration (T-0039,
T-0040 do those). The stack is what makes afterburn look like a photographed
diorama: MRT → SSGI → SSR → god rays → TRAA → DOF → bloom → AgX → grade →
vignette → grain.

## Context
- **Read first**: `docs/gpu.md` §1–3 and §8 (this repo's contract for the
  wave), then `~/afterburn/src/render/pipeline.js` and `renderer.js`. Copy
  them; do not redesign. The user has authorised copying freely.
- Verified facts about this repo's three (r185.1, already a dependency — **do
  not add any npm package**): `THREE.RenderPipeline` exists in `three/webgpu`;
  `three/tsl` exports the node functions afterburn imports; and
  `three/addons/tsl/display/{SSGINode,SSRNode,GTAONode,TRAANode,FXAANode,
  BloomNode,DepthOfFieldNode,GodraysNode,BilateralBlurNode,depthAwareBlend}.js`
  all exist. `three/webgpu` and `three/tsl` import cleanly under node 22.
- Keep verbatim, because that block *is* the look: `pipeline.outputColorTransform
  = false`, the `renderOutput` AgX step, the split-tone (`shadowTint` →
  `highlightTint` by luminance), contrast around mid grey, saturation,
  vignette, `interleavedGradientNoise` grain, and the `fade` multiply.
- Keep the `QUALITY` table (`low|medium|high|ultra`) and `createLook()`
  defaults as afterburn has them; keep the `giScale` knob its SSGI branch
  already reads, and the `maxRadiance` firefly clamp before TRAA.
- **Testability split (this is the design decision — do not deviate).**
  Nothing in `tests/` may touch a GPU. So the module exports two *pure*
  functions alongside the impure builder:
  - `export function clampQuality(requested: QualityName, caps: RendererCaps): QualityName`
    — the `caps.maxQuality` rule from `docs/gpu.md` §3 (a non-WebGPU backend,
    or an MRT budget under 64 bytes, caps at `'medium'`).
  - `export function qualityPlan(name: QualityName, override?: Partial<QualitySettings>): QualitySettings`
    — resolves the table entry plus the dev override into the flags `build()`
    then consumes.
  `createPipeline()` calls `qualityPlan` and builds the graph; `setQuality`
  rebuilds only when the resolved name actually changes.
- `createRenderer()` keeps afterburn's adapter probe, the
  `requiredLimits.maxColorAttachmentBytesPerSample = 64` request, AgX tone
  mapping at exposure 1.0, PCF soft shadows, `await renderer.init()`, and the
  `caps = { webgpu, mrtBytes, maxQuality }` return. It must never throw for a
  missing `navigator.gpu` — the WebGL2 fallback backend is a supported
  outcome (`docs/gpu.md` §3).
- TS strict, named exports, no `any`, relative imports end in `.js`, one-line
  JSDoc on every export. These files are browser-only: they may use DOM and
  WebGPU types, and are typechecked by `web/tsconfig.json` (which already
  includes `src/gpu/**/*.ts`). `tests/gpu-pipeline.test.ts` is compiled by the
  root tsconfig (no DOM lib), so **only import the pure exports from the test**
  — do not import `renderer.ts` there.
