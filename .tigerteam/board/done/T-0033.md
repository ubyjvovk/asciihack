## Context
- **Lattice fades out within ~8 cells.** In `src/render/ortho.ts` the
  unexplored lattice seams (0.09 absolute, T-0027) are multiplied by the
  same distance fog as the floor (`exp(−0.06·dist)`), so beyond ~8 cells
  from the hero they drop under the quantizer's black point and the void
  goes black again — the user asked for a grid so the room never floats.
  Give the lattice its own gentle fade: `exp(−0.015·dist)` (still a hint
  of distance, visible across the whole viewport). Update the
  `unexplored cells carry the lattice` test to also assert a seam 20 cells
  from the hero is still above the black point (`value·1.7 > 0.10`).
  Regenerate both ortho goldens.
- **Docs sync.** `docs/ui.md`'s CLI section still describes `--playground`
  as the *source* playground; since T-0014 it is the per-player target
  directory (copied from `build/nethack/bridge/playground` on first use,
  default `~/.asciihack/playground`, `ASCIIHACK_HOME` honoured). Fix that
  paragraph to match `README.md` and `docs/ssh.md`.
